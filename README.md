# مرحباً أيها المستخدم، افتحني

تطبيق رعب تجريبي للأندرويد، مستوحى من البرامج الغامضة ذات المظهر القديم في الفترة 2014–2016.

## المميزات
- واجهة ورسائل عربية.
- تصميم بسيط مستوحى من برامج الكمبيوتر القديمة.
- شاشات خطأ حمراء خيالية داخل التطبيق.
- شخصية ظل غامضة مرسومة رقمياً.
- رسائل متغيرة وسجل نشاط.
- مؤثرات صوتية اختيارية بمستوى محدود.
- زر إيقاف ظاهر ويمكن استخدامه في أي وقت.

## الأمان
هذا التطبيق محاكاة ترفيهية فقط. لا يقفل الهاتف، ولا يغيّر إعدادات Android، ولا يصل إلى الملفات الشخصية، ولا يعمل في الخلفية. تبدأ المؤثرات الصوتية بعد ضغط المستخدم على زر بدء التجربة، ويمكن إيقافها من زر الصوت أو إيقاف التجربة.

## البناء
1. افتح المشروع في Android Studio.
2. انتظر انتهاء Gradle Sync.
3. اختر Build > Build APK(s).

معرّف التطبيق: `com.marhaban.openme`
